O que aprendi no curso

  • git init — começa um repositório
  • git status — mostra o que mudou
  • git add — prepara os arquivos
  • git commit — salva uma "foto" do projeto
  • git remote — liga ao GitHub
  • git push / git pull — envia e baixa mudanças
  • git clone — copia um repositório
