# Meu primeiro repositório

Projeto criado para praticar o que aprendi no curso de **Git**.
É uma página simples em HTML e CSS que resume os comandos que estudei.

## Como ver o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/meu-primeiro-repositorio.git
   ```
2. Abra o arquivo `index.html` no navegador.

## Comandos que pratiquei

| Comando        | Para que serve                          |
| -------------- | --------------------------------------- |
| `git init`     | Cria um repositório novo na pasta       |
| `git status`   | Mostra o que mudou desde o último commit |
| `git add`      | Coloca arquivos na "área de preparo"    |
| `git commit`   | Salva uma versão do projeto             |
| `git remote`   | Conecta o projeto ao GitHub             |
| `git push`     | Envia os commits para o GitHub          |
| `git pull`     | Baixa as mudanças do GitHub             |
| `git clone`    | Copia um repositório para o computador  |

## Tecnologias

- HTML
- CSS
- Git e GitHub
